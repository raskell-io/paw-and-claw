# Sprite Prompt Notes

Background material for the sprite pipeline. **Prompts themselves live in
[`../manifest.json`](../manifest.json)**, and the workflow is documented in
[`../README.md`](../README.md).

- `art-direction.md`: visual identity and faction looks
- `palette.md`: faction, terrain and UI colors
- `ui/`: prompts for UI icons (not yet in the manifest)
